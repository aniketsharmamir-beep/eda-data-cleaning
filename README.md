# EDA and Data Cleaning: Titanic Dataset

## Objective
Clean a real-world dataset and explore it using Python, Pandas, and Seaborn.

## Dataset Source
Titanic dataset (Kaggle). 891 passengers, 12 columns.

## How to Run the Notebook
1. Open notebooks/eda_and_cleaning.ipynb in Google Colab.
2. Upload data/raw_dataset.csv to the Colab Files panel.
3. Click Runtime, then Run all.

## Repository Structure
- data/raw_dataset.csv - original data
- data/cleaned_dataset.csv - cleaned data
- notebooks/eda_and_cleaning.ipynb - code and notes
- docs/summary_report.pdf - findings report
